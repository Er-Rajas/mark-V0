# mark-V0
A mini DataAnalyst Mk0

## Description
A mini DataAnalyst Mk0 is a simple AI agent designed to perform basic data analysis tasks on a given dataset. It uses a pre-trained model to generate responses based on the input provided.

## Usage
To use the mini DataAnalyst Mk0, you need to provide a dataset in the form of a pandas DataFrame. The agent will then generate a response based on the input provided.\
